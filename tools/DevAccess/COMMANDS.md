## 2. CVars (reflected config fields)

CVar names are **not stored whole** in the binary. The reflection system stores a `ConsolePrefix`
string once per config class and the member name separately; the console command is `<prefix><member>`.
This is why `env_Hour` / `cheat_UnlimitedAmmo` return zero literal hits yet are real.
